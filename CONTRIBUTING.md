# Contributing

pixel-press is open source under the MIT license, but it is maintained by a single author and **does not accept outside contributions**: pull requests and feature requests will be closed without review.

You are free to fork, copy, modify, and redistribute the project under the terms of the [MIT license](LICENSE). If you want changes, forking is the way.

Security problems can be reported privately to the maintainer (see the repository owner's profile for contact details).
